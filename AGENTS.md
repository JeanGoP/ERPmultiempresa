# Instrucciones del proyecto

Al terminar cada trabajo de implementación:

1. Ejecutar las validaciones proporcionales al cambio y corregir sus errores.
2. Crear un commit con un mensaje claro en español.
3. Después del commit, ejecutar `npm run publish:manual` para dejar exclusivamente el backend compilado en la carpeta local ignorada `publish/`.
4. Informar el hash del commit, las validaciones realizadas y la ubicación del paquete generado.

No incluir secretos ni bases de datos locales en el commit o en `publish/`.
